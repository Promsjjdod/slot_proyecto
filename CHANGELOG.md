# Changelog

All notable changes to **Bruma de Jade: Calderos del Alba** are recorded here.

## [0.1.0] — 2026-10-13

### Added

- Original mobile-first 5×3 PixiJS slot experience with 243 ways, responsive HUD, jackpots, Pot vessels and virtual demo credits.
- Seeded reel engine, weighted reel strips, Hold & Spin, progressive Pot tiers, configurable 18% coin upgrade chance and independently calibrated Buy Feature confirmation.
- Vitest coverage, a deterministic 10-million-spin RTP simulator, and a Buy Feature cost simulator; base RTP CI tolerance is ±1 percentage point.
- Original hybrid art direction, generated mist-mountain backdrop, vector symbol atlas, procedural MP3 music/SFX and Howler mixing controls.
- Paytable, rules, history, ES/EN settings, reduced-motion support, PWA shell, docs and GitHub Pages CI/deploy workflow.
